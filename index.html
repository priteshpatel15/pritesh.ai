Agent control

The agent says it is done. Is it?

Coding agents report success when nothing ran. I kept hitting this while building with them, so I stopped reading agent reports and started demanding evidence a program can check: a command, its exit code, a trace event the agent did not write.

That works while the checker is simple and the agent is not trying to fool it. I want to know what holds when neither is true.

A CLI that will not mark work complete without command-backed evidence.

Codesdd-harness. Spec first, red and green tests, browser proof, all saved as files. TypeScript.

A scorer that grades a deliverable and its trace by counting evidence, not by asking a model.

Codeagent-output-eval. "All tests pass" with no test event fails a gate. Python, no dependencies.

Plain-English questions over data, with model-written code run in a restricted executor.

Codecurex. Python.
