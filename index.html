The agent says it is done. Is it?

I am Pritesh Patel. I build tools that check whether AI agents did what they say they did. I want to work on that problem as research: how to keep oversight of systems that are more capable than the person reviewing them.

The question

Coding agents report success when nothing ran. I kept hitting this while building with coding agents, so I stopped reading agent reports and started demanding evidence a program can check: a command, its exit code, a trace event the agent did not write.

That works while the checker is simple and the agent is not trying to fool it. I want to know what holds when neither is true.

Work

  • A CLI that will not mark work complete without command-backed evidence.

    Evidencesdd-harness. Spec first, red/green tests, Playwright proof, all saved as files. TypeScript.

  • A scorer that grades a deliverable and its trace by counting evidence, not by asking a model.

    Evidenceagent-output-eval. "All tests pass" with no test event fails a gate. Python, no dependencies.

  • Plain-English questions over data, with model-written code run in a restricted executor.

    Evidencecurex. Python.
