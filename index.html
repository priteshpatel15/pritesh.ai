Latest obsession

Keeping AI telling the truth.

I build with AI agents every day. They tell me work is finished when it is not. So I stopped reading their reports and started demanding evidence a program can check: a command, its exit code, a trace the agent did not write.

  • sdd-harness. A command-line tool that makes a coding agent write the spec first, show a failing test, then a passing one. It refuses to mark work complete without that proof.

    Agents skip steps when nothing checks them. Asking nicely did not work.

  • agent-output-eval. A scorer for what an agent delivers and the record of how it got there. It counts evidence. If a report says "all tests pass" and no test ran, it fails.

    Asking a second model to grade the first only moves the trust problem.

  • dev-command-library. A set of commands that takes an agent from design to a finished change, one small step at a time, with a size limit on each step.

    Big changes are where agents drift and where false claims hide.

This works while the checker is simple and the agent is not trying to fool it. I want to know what holds when neither is true.

  • A live budget on my phone. Bank exports land in a shared sheet, and categories learn from my corrections.

    I wanted to see this month's spending without opening five bank sites.

  • A priority board run by an agent. It sorts my week by energy and deadline, then does the tasks it can.

    My best thinking hours kept going to small tasks.

  • Paper mail and receipts. Scanned mail is sorted into actions. Email receipts become proof an accountant will accept.

    The pile on the counter was not going to read itself.

Data and documents

Restaurant technology

I have more than ten years of experience in a family restaurant business. I keep trying to fix its problems with software.

  • Automated books for a frozen-yogurt shop. Bank, payroll, register, delivery and supplier files go in. A finished profit-and-loss statement comes out.

    The owner should not need an accountant to know if last month made money.

  • Item-level demand forecasting. Predicts what will sell each day from weather, local events and what is nearby.

    Over-ordering is waste and under-ordering is lost sales.

  • Streakss, StreetRoll and MenuSales.ai. Three startups: guest rewards, food-truck location prediction, and an AI menu assistant.

    I thought restaurants would pay for these. I ran pilots with five customers and tested thoroughly. They did not get traction, and I learned a great deal.
